# 📍 SpotFinder

O **SpotFinder** é uma plataforma inovadora desenhada para ligar os utilizadores aos melhores eventos em Portugal. Desde concertos a exposições, a nossa missão é facilitar a descoberta de experiências culturais e de lazer através de uma interface intuitiva e tecnológica.

---

## 🚀 Funcionalidades Principais

* **🤖 Chatbot Inteligente:** Um assistente virtual dedicado para ajudar na navegação e responder a dúvidas sobre os eventos.
* **🗺️ Mapa Interativo:** Visualiza geograficamente todos os eventos a decorrer e encontra o que está mais perto de ti.
* **🎟️ Bilheteira Integrada:** Compra os teus bilhetes de forma rápida, segura e sem complicações diretamente na aplicação.
* **🇵🇹 Cobertura Nacional:** Foco total no território português, garantindo que não perdes nada do que acontece de Norte a Sul.
