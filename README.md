# ESTG-ESI-SpotFinder
Equipa de desenvolvimento: Dinis Soares, Hermengildo Brito, Henrique Jones, Pedro Amaral, Daniel Cozmac, Luis Rios.
O SpotFinder é uma ferramenta que ajuda o utilizador a encontrar eventos em Portugal. Tem um sistema de chatbot, mapa interativo, funcionalidade de compra de bilhetes.
